# 优化器模块文档

本模块定义了神经网络模型可学习参数的迭代优化更新、梯度裁剪以及学习率调度管理积木。

---

## 1. 参数优化算法（命令积木）

框架内置了从基础随机梯度下降到现代自适应动量估计的主流优化算子。

### 1.1 SGD + Momentum
```scratch
[执行 SGD 优化器 学习率: <浮点数 lr> 动量: <浮点数 momentum> 权重衰减: <浮点数 weight_decay>]
```
- **参数说明**：
  - `学习率 lr`（默认 `0.01`）：控制每次迭代梯度下降的更新步长大小。
  - `动量 momentum`（默认 `0.9`）：累积历史梯度更新趋势，在梯度振荡区域加速收敛并减少穿越鞍点阻力。设为 `0` 即为基础 SGD。
  - `权重衰减 weight_decay`（默认 `0`）：对可学习参数施加 L2 正则化惩罚，将 `weight_decay * param` 加到梯度上后再执行参数更新，防止模型过拟合。
- **SGD 底层 API**：`sgdStep(lr, momentum, weightDecay)` 默认 `momentum = 0.9`。

---

### 1.2 Adam / AdamW
```scratch
[执行 Adam 优化器 学习率: <浮点数 lr> Beta1: <0.9> Beta2: <0.999> 权重衰减: <0.0>]

[执行 AdamW 优化器 学习率: <浮点数 lr> Beta1: <0.9> Beta2: <0.999> 权重衰减: <0.01>]
```
- **核心逻辑与特性**：
  1. **自动动量状态管理**：系统会针对全局所有注册且 `需梯度: true` 的可学习参数叶子节点（Leaf Tensors），在后端自动维护一阶动量均值与二阶梯度方差缓存。
  2. **AdamW 解耦权重衰减**：在大语言模型与 Transformer 架构训练中事实上的标准优化算法，将权重衰减与梯度动量更新解耦（即 `param -= lr * wd * param`，而非加到梯度上），取得比传统 Adam 更稳定的泛化表现。
  3. **Plain Adam 的权重衰减**：Adam（非 AdamW）的权重衰减采用经典 L2 正则化方式，将 `weight_decay * param` 加到梯度上，再进入 Adam 动量更新流程。
  4. **epsilon 数值稳定项**：Adam/AdamW 底层使用 `eps = 1e-8` 防止除数过小导致数值溢出。此常量硬编码，不通过积木暴露。
  5. 优化器更新完毕后对常数或训练样本数据等未开启梯度的节点不产生影响。
  6. **生命周期绑定**：调用 `[删除所有 Tensor]` 或底层 `clearTensorRegistry()` 时会自动清空所有优化器状态（momentum 缓存、Adam 一阶/二阶矩、步数**、以及全局学习率缩放系数（重置为 `1.0`）**），防止旧模型参数缓存污染新训练。

## 2. 梯度裁剪保护（命令积木）

针对深层网络、RNN/LSTM 或 Transformer 模型在训练初期可能面临的梯度爆炸（Gradient Explosion）问题，提供全局范数梯度裁剪：

```scratch
[对所有参数执行梯度裁剪 最大阈值: <浮点数 max_norm>]
```
- **执行时机**：应置于 `[对 Tensor ... 进行反向传播]` 之后，且在 `[执行 Adam/SGD 优化器]` 之前调用。
- **执行逻辑**：自动计算全部参数 `.grad` 的全局 L2 范数；若范数超过最大阈值，自动将所有参数梯度等比例压缩至上限之内。若 `max_norm <= 0`，静默跳过不裁剪。
- **默认值**：`max_norm = 1.0`。

---

## 3. 学习率动态调度（命令积木）

在不同训练阶段动态调节优化器学习率（如预热 Warmup、衰减 Decay）：

```scratch
[设置优化器全局学习率缩放系数为: <浮点数 scale_factor>]
```
- **常见用法**：在每隔若干 Epoch 迭代结束后，传入系数（例如 `0.1` 表示学习率衰减至原先的 10%），实现平滑精准收敛。
- **注意**：此缩放系数会在 `[删除所有 Tensor]` 时自动重置为 `1.0`。
