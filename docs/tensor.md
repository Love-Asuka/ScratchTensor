# Tensor 模块文档

本模块提供 Tensor的创建、数据访问、高级结构变形操作以及模型参数序列化导入导出的积木。

---

## 1. 语法与参数类型约定

在本框架中，严格按照Scratch范式区分积木类型与输入类型：

- `[...]` **方形命令积木（Command Block）**：不返回值，用于产生创建、赋值、注册等生命周期操作。
- `(...)` **椭圆报告积木（Reporter Block）**：具有返回值（如数值JSON、Shape），嵌入其它积木的槽位中。
- **输入类型标识**：
  - `"名称"`：表示 **字符串名称（String）**，用于指定或查询全局注册的 Tensor 名称。张量在积木层只通过字符串名称传递。
  - `<数值/Shape>`：表示 **数值、数组或布尔常量**，如形状 `[10, 5]`、布尔值 `true`/`false`。

---

## 2. 创建 Tensor（命令积木）

```scratch
[创建 Tensor 命名为 "tensor_name" 并赋值 <多维数组> 需梯度: <布尔值 true/false>]

[创建形状为 <Shape数组> 的随机正态分布 Tensor 命名为 "tensor_name" 需梯度: <布尔值 true/false>]

[创建形状为 <Shape数组> 的全0 Tensor 命名为 "tensor_name" 需梯度: <布尔值 true/false>]

[创建形状为 <Shape数组> 的全1 Tensor 命名为 "tensor_name" 需梯度: <布尔值 true/false>]
```

### 参数说明
- **`"tensor_name"` (String)**：Tensor 的唯一字符串注册名。
- **`<Shape数组>` / `<多维数组>`**：例如 `[64, 128]` 或 `[[1.0, 2.0], [3.0, 4.0]]`。
- **`需梯度:` (Boolean)**：
  - `true`：后端将该 Tensor 标记为 **持久化模型可学习参数（Leaf Parameter）**，长期驻留显存/内存，并在反向传播时为其实例化 `.grad` 属性以供优化器更新。
  - `false`：标记为 **常规数据或常数张量**（如训练样本输入、真实标签等），不参与优化器梯度更新。
- **默认值**：`创建 Tensor` 与 `randomNormal` 积木默认 `true`（用户创建权重时常见）；`zeros`/`ones` 积木默认 `false`（常用于创建偏置或占位）。

---

## 3. 获取 Tensor 信息（报告积木 - 椭圆）

（注：系统底层维护数字 ID 仅供后端图引擎优化管理，前端图形积木层仅通过字符串 `"名称"` 传递数据流。）

```scratch
(获取 Tensor "tensor_name" 的 [PROPERTY])
```
- **输入类型**：`"tensor_name"` 字符串名称；`[PROPERTY]` 下拉选项：数值 / 标量值 / Shape / 梯度。
- **返回值**（注意：报告积木在 Scratch 中返回字符串）：
  - 数值：返回该 Tensor 底层数据序列化为 JSON 字符串，如 `[[1.0,2.0],[3.0,4.0]]`（常用于测试评估与界面调试渲染）。
  - 标量值：对单元素张量调用 `item()` 返回标量数值；若张量非标量，返回错误消息。
  - Shape：返回形状的 JSON 字符串，例如 `[32, 128]`。
  - 梯度：返回该 Tensor 累积梯度的 JSON 字符串；若该 Tensor 不存在、未开启梯度或尚未执行反向传播，则返回字符串 `'null'`。

## 4. Tensor 删除与生命周期管理（命令积木）

为了避免长期运行或重复创建张量时导致的内存泄漏，框架提供显式删除积木。

### 4.1 删除单个 Tensor

```scratch
[删除 Tensor "tensor_name"]
```
- **参数说明**：`"tensor_name"` 为待删除张量的全局注册名。
- **执行逻辑**：从全局注册表 `tensorByName` 与 `tensorById` 中移除该张量，释放其 `NDArray` 数据引用，使其可被垃圾回收。
- **安全提示**：
  - 删除后不能再通过 `"tensor_name"` 访问该张量；若仍有本地变量引用，引用本身不会失效，但无法通过名称重新查找。
  - 若该张量作为其他张量的输入仍在反向传播图中使用，建议在 `[对 Tensor ... 进行反向传播]` 完成后再执行删除，否则可能破坏后续计算图。

### 4.2 删除所有 Tensor

```scratch
[删除所有 Tensor]
```
- **执行逻辑**：清空全局张量注册表，同时触发优化器状态缓存（momentum、Adam 一阶/二阶矩）及全局学习率缩放系数（重置为 `1.0`）清空，等价于调用底层 `clearTensorRegistry()`。
- **使用场景**：训练结束、切换模型、重置环境或 Scratch 项目重新运行前调用。
- **注意**：此操作会删除所有叶子参数（可学习权重），下次训练前需要重新创建参数。

### 4.3 反向传播积木

```scratch
[对 Tensor "Tensor名称" 进行反向传播]
```
- **参数说明**：`"Tensor名称"` 为待反向传播的损失标量 Tensor 的名称。
- 详细执行逻辑见 `docs/autograd.md`。

### 4.4 自动清理机制

当执行 `[对 Tensor "loss" 进行反向传播]` 时，Autograd 引擎会自动：
1. 将非叶子中间节点的 `creatorOp` 和 `grad` 置空；
2. 把这些中间节点从全局注册表中移除（保留目标 `loss` 张量本身）。

因此，一次完整的 `forward → backward` 后，中间激活张量不会继续占用注册表内存。用户只需要手动删除长期保留的临时张量或调用 `[删除所有 Tensor]` 重置环境。

## 5. 形状与结构变换积木

### 5.1 重塑与转置 (Reshape / Transpose)

```scratch
[将 Tensor "Tensor名称" 重塑(Reshape)为 <Shape数组> 赋值给 "输出名称"]

[将 Tensor "Tensor名称" 转置(Transpose) 维度 <数字 dim1> 和 <数字 dim2> 赋值给 "输出名称"]
```
- **参数说明**：
  - `<Shape数组>`：目标形状，元素总数须与原张量一致；某一维可填 `-1` 自动推导。
  - `<数字 dim1>`, `<数字 dim2>`：要交换的两条维度下标（支持负数索引）。

### 5.2 维度扩展、缩减与形状广播 (Unsqueeze / Squeeze / Expand)

在进行注意力运算或偏置加法时，常需在张量的特定轴上增加或缩减维度。

#### 标准命令积木（方形）
```scratch
[在 Tensor "Tensor名称" 的维度 <数字 dim> 插入新维度(Unsqueeze) 赋值给 "输出名称"]

[移除 Tensor "Tensor名称" 大小为 1 的维度(Squeeze) 赋值给 "输出名称"]

[将 Tensor "Tensor名称" 广播(Expand)至目标形状 <Shape数组> 赋值给 "输出名称"]
```
- **参数说明**：
  - `<数字 dim>`：维度下标（支持负数索引，如 `-1` 表示最后一个维度；也支持 `dim = ndim` 表示在张量尾部追加新维度）。
  - `<Shape数组>`：广播目标形状（要求原张量各维度大小符合广播法则，例如 `[1, 128]` 扩展至 `[32, 128]`）。

---

### 5.3 张量拼接、分割与堆叠 (Concat / Split / Stack)

用于残差网络多路特征融合、多模态输入处理或序列拆解。

#### 标准命令积木（方形）
```scratch
[拼接张量列表: <名称字符串数组> 沿维度: <数字 dim> 赋值给 "输出名称"]

[堆叠张量列表: <名称字符串数组> 在新维度: <数字 dim> 赋值给 "输出名称"]

[将 Tensor "Tensor名称" 沿维度 <数字 dim> 均分为 <数字 n> 份 赋值前缀为 "输出前缀"]
```
- **示例说明**：
  - `Concat`（拼接）：不增加张量的总维度数量，仅在指定轴上合并长度（如把两个形状 `[10, 32]` 沿维度 1 拼接得到 `[10, 64]`）。
  - `Stack`（堆叠）：插入一个全新维度将多个相同形状的张量打包（如把两组 `[10, 32]` 在维度 0 堆叠得到 `[2, 10, 32]`）。
- **注意**：Concat 与 Stack 要求至少提供 **2 个**有效张量名称；若不足则静默不执行。

---

### 5.4 索引切片与掩码选值 (Slice / Masked Where)

用于截取序列片段（例如自然语言处理中的输入词元截断）以及生成或应用注意力掩码（Causal Mask / Padding Mask）。

#### 标准命令积木（方形）
```scratch
[截取 Tensor "Tensor名称" 沿维度 <数字 dim> 从索引 <起 index_start> 到 <止 index_end> 赋值给 "输出名称"]

[条件选择(Where): 条件 "布尔Tensor名" 为真取 "Tensor名1" 为假取 "Tensor名2" 赋值给 "输出名称"]
```
- **执行说明**：
  - **切片操作 (Slice)**：自动保留反向传播追踪，仅将梯度回传至对应被截断部分的输入节点。
  - **条件选择 (Where)**：根据掩码张量按元素分支选择，对被选中的路径传播反向梯度。三个输入支持广播到公共形状。

---

### 5.5 数值范围裁剪 (Clamp / Clip)

防止深层模型出现梯度爆炸或在特定场景约束输出范围。

#### 标准命令积木（方形）
```scratch
[将 Tensor "Tensor名称" 裁剪数值范围至 <最小值 min_val> 到 <最大值 max_val> 之间 赋值给 "输出名称"]
```

---

## 6. 模型参数序列化与导入导出

在完成模型训练后，将学到的神经网络权重导出并重载复用，是框架闭环的核心能力。

由于 Scratch 浏览器扩展无法直接读写本地文件，模型序列化通过 JSON 文本字符串进行：保存时可将 JSON 字符串写入 Scratch 变量或借助外部方式下载，加载时直接读取 JSON 文本字符串恢复权重。

ScratchTensor 采用**名称空间优先**与局部运行时 **ID** 的设计模式，导出的 StateDict 保存 `name`（名称）、`id`、`shape` 与 `data`（底层多维数值数组）。

### 6.1 权重字典格式规范 (JSON / StateDict)

导出生成的模型权重文件（通常保存为 `.json` 或 `.stweights`）格式示例如下：

```json
{
  "framework": "ScratchTensor",
  "tensors": [
    {
      "name": "模型权重W",
      "id": 101,
      "shape": [5, 1],
      "requires_grad": true,
      "data": [
        [0.1234],
        [-0.4567],
        [0.8891],
        [0.0345],
        [0.7210]
      ]
    },
    {
      "name": "模型偏置b",
      "id": 102,
      "shape": [1],
      "requires_grad": true,
      "data": [0.0512]
    }
  ]
}
```

- **序列化优势**：
  1. **直观易读且跨平台兼容**：JSON 文本可以直接通过前端网页下载为本地文件，亦可在 Scratch 列表中复制粘贴传递。
  2. **双重匹配与对齐**：导入时优先按照 `"name"` 进行全局名称空间精准对齐覆盖；未创建的参数可根据 `name`、`shape` 与 `data` **零配置自动重建并分配运行时 ID**。

---

### 6.2 模型导出积木

Scratch 浏览器扩展无法直接读写本地文件，因此提供 JSON 文本导出积木：

```scratch
(获取当前模型权重字典 JSON 字符串)
```
- **使用场景**：可以作为长字符串直接写入界面文本框、保存至 Scratch 全局变量，或借助外部方式下载为 `.json` 文件。

---

### 6.3 模型导入与参数恢复积木

支持从 JSON 文本字符串恢复权重：

```scratch
[从 StateDict 文本 <JSON文本字符串> 导入并恢复模型权重]
```

- **系统对齐恢复执行逻辑**：
  1. 遍历 JSON 中的每个 `tensors` 条目；
  2. **已存在名称匹配**：若系统已注册对应 `name` 的 Tensor，自动检验 `shape` 一致性，将底层参数覆盖更新为记录的 `data` 并自动清空原先可能的 `.grad` 缓存；
  3. **未注册参数自动恢复**：若系统内存表中尚未创建对应的 `name`，框架将依据记录的 `name`、`shape`、`requires_grad` 及 `data` 自动在当前运行时实例化张量并分配新 `ID`。

---

## 7. 边界与错误处理说明

ScratchTensor 扩展层（Scratch 积木）对非法输入的容错策略：

- **创建类积木**（创建 Tensor / 全 0 / 全 1 / 随机正态）：当输入的数组 / 形状 JSON 解析失败时，会抛出错误，不再静默回退为标量 `[1]`。
- **形状类积木**（Reshape / Expand / Concat / Stack）：当输入的形状字符串解析失败，或提供的张量数量不足（Concat/Stack 要求 ≥2 个）时，会静默不执行。
- **读取类报告积木**：当目标 Tensor 不存在时返回 `'null'` 字符串；梯度不存在或未计算同样返回 `'null'` 字符串。
- **删除类积木**：`[删除 Tensor "name"]` 对不存在的名称静默不执行；`[删除所有 Tensor]` 无参数，会强制清空注册表与优化器状态（含学习率缩放系数重置为 `1.0`）。

在底层 TypeScript API 调用中，非法维度、不兼容广播、`slice` 越界等操作会抛出明确的 `Error`。
