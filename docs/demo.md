# 综合应用：模拟神经网络训练文档

本指南结合前面定义的各个积木模块，展示如何在 ScratchTensor 中以完全契合 Scratch 官方语法与深度学习动态图逻辑的方式构建模型训练程序。

---

## 1. 积木语法与 Scratch 机制约束

为了确保设计不仅逻辑自洽，还能在 Scratch 积木编程体系下可行：
- **方形命令积木 `[...]`**：无返回值。负责控制执行流程、计算图推导以及将其结果绑定给目标名称。
- **椭圆报告积木 `(...)`**：部分内置纯函数（如 Tensor 信息查询、StateDict 导出）作为快捷表达式积木使用。
- **关于 Scratch 自制积木的严格规则**：
  Scratch 官方的自制积木只支持**方形命令积木（无返回值）**！因此，在封装神经网络层（如 Linear 层）时，通过在参数中传入一个 **`输出名称`** 字符串，由积木内部将新产出的节点绑定给该名称，调用完毕后直接通过字符串 `"输出名称"` 访问计算结果。

---

## 2. 自制神经网络层积木

下面示范封装一个带可选偏置的全连接线性层（`Linear层`）：
- 通过传入输入名称、权重名称以及可选偏置开关 `使用偏置:` 和偏置名称；
- 内部运用 Scratch 原生的**条件分支 `如果...那么...否则` 控制流**动态构建有向计算图；
- 结合自动广播加法算子 `+`，展示 ScratchTensor 在图形化控制流下构建灵活神经网络拓扑的强大表达能力。

```scratch
[定义自制积木 Linear层 输入名称: "输入X" 权重名称: "权重W" 使用偏置: <布尔值 use_bias> 偏置名称: "偏置b" 输出名称: <字符串 out_name>] {
    // 1. 先进行矩阵乘积运算 Y_matmul = X * W
    [张量 "输入X" 与 "权重W" 进行 [@] 运算 赋值给 "临时矩阵积"]
    
    // 2. 利用 Scratch 流程控制分支，动态决定是否在计算图中加入偏置广义加法节点
    如果 <布尔值 use_bias> = true 那么 {
        // 利用形状广播机制叠加偏置参数：Y = X * W + b
        [张量 "临时矩阵积" 与 "偏置b" 进行 [+] 运算 赋值给 <字符串 out_name>]
    } 否则 {
        // 无偏置模式直接绑定矩阵乘积输出
        [张量 "输入X" 与 "权重W" 进行 [@] 运算 赋值给 <字符串 out_name>]
    }
}
```

## 3. 完整训练循环示例

在训练闭环中：
1. 模型权重与偏置参数均设为 `需梯度: true`（叶子参数），训练样本与标签设为 `需梯度: false`；
2. 反向传播触发时，Autograd 自动求导引擎会根据当轮运行分支（带有偏置项的计算拓扑）自动反传计算 `模型权重W` 和 `模型偏置b` 的导数；
3. `执行 SGD 优化器` 将自动对所有处于叶子状态的模型可学习参数完成单步梯度下降更新。

```scratch
[创建形状为 [10, 5] 的随机正态分布 Tensor 命名为 "样本数据" 需梯度: false]
[创建形状为 [10, 1] 的随机正态分布 Tensor 命名为 "真实标签" 需梯度: false]

[创建形状为 [5, 1] 的随机正态分布 Tensor 命名为 "模型权重W" 需梯度: true]
[创建形状为 [1] 的全0 Tensor 命名为 "模型偏置b" 需梯度: true]

[设置计算图追踪: true]

循环 100 次 {
    [Linear层 输入名称: "样本数据" 权重名称: "模型权重W" 使用偏置: true 偏置名称: "模型偏置b" 输出名称: "预测输出"]
    
    [MSELoss 预测: "预测输出" 真实标签: "真实标签" 赋值给 "当前Loss"]

    // 自目标损失出发，自动向权重与偏置完成反向导数传导
    [对 Tensor "当前Loss" 进行反向传播]
    
    // 一键遍历全部持久化叶子模型参数（W 和 b）执行优化更新
    [执行 SGD 优化器 学习率: 0.01 动量: 0.9 权重衰减: 0]

    // 清空梯度缓存，为下一轮迭代做准备
    [清空所有参数梯度]

    // 可选：删除本轮不再需要的临时张量（如中间特征、loss），进一步降低内存占用
    [删除 Tensor "预测输出"]
    [删除 Tensor "当前Loss"]
}

// 训练结束后可删除所有张量并释放优化器缓存
[删除所有 Tensor]
```

### 内存管理说明
- 每轮 `forward → backward` 后，Autograd 会自动从注册表中移除非叶子中间节点（如 `Linear层` 内部的 `临时矩阵积`），无需手动处理。
- 若某轮产生了额外需要长期保留的临时张量（例如用于可视化的中间结果），建议使用 `[删除 Tensor "..."]` 在用完之后释放。
- 切换模型、重新开始训练或项目结束时，使用 `[删除所有 Tensor]` 可以一次性清空张量与优化器状态。
