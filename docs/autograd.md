# Autograd 自动求导模块文档

本模块用于计算图的动态追踪控制、误差反向传播及梯度清空。

---

## 1. 计算图追踪控制（命令积木）

```scratch
[设置计算图追踪: <布尔值 true/false>]
```

### 参数说明
- **`<布尔值>`**：传入 `true` 或 `false`。
  - **`true`（默认状态）**：此后发生的所有算子运算（矩阵乘法、激活函数、损失计算等）会自动在计算图中创建动态运算节点，并将算子及输入/输出 Tensor ID 关联至当前图。
  - **`false`（No-Grad 模式）**：用于模型推理（Inference）或验证阶段。不再生成中间求导拓扑，极大节省内存占用并加速前向计算。

底层提供 `isGraphTracking()` 查询函数，可随时检查当前计算图追踪是否开启。

---

## 2. 反向传播（命令积木）

```scratch
[对 Tensor "Tensor名称" 进行反向传播]
```

### 参数说明
- **`"Tensor名称"` (String)**：待求导标量目标（通常为 Loss 损失表达式产出的 Tensor 名称）。Scratch 扩展层会将字符串名称解析为对应的 TensorNode 对象后调用底层 `backward()`。
- **前置条件**：若目标张量既无 `creatorOp`（即并非由任何算子产生），也未开启 `requiresGrad`，则 `backward` 会静默返回，不做任何操作。这常见于对纯数据张量（无计算图链路的常量）调用反向传播。
- **梯度自动初始化**：若目标张量的 `.grad` 为空，反向传播前会自动将其初始化为全 1（对标量损失张量即为 `[1]`），与 PyTorch 约定一致 —— 损失对自身的导数为 1。
- **执行逻辑**：
  1. 从传入的损失标量节点出发，沿当轮记录的动态有向无环计算图后向遍历。
  2. 遇到 `需梯度: true` 的持久化可学习模型参数（Leaf Tensors），自动求导并将其累加到该参数的 `.grad` 属性中。
  3. 中间临时运算产生的节点（Non-Leaf Tensors）不会被误作为持久化参数存储。
  4. **内存释放**：反向传播完成后，所有非叶子中间节点会从全局注册表中移除（`creatorOp` 与 `grad` 也会被清空），使其底层数据可被垃圾回收。目标 `loss` 张量本身会保留，便于后续查看损失值。

---

## 3. 清空梯度（命令积木）

```scratch
[清空所有参数梯度]
```

### 执行说明
- **作用**：清空所有后台注册的叶子模型参数（`需梯度: true`）上的 `.grad` 缓存，避免梯度在多个 step 之间累加。
- **计算图清理**：中间临时节点的计算图释放发生在 `[对 Tensor ... 进行反向传播]` 内部，而非本积木。
