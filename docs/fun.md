# 函数与算子模块文档

本模块包含 ScratchTensor 中的深度学习算子与基础计算积木。

由于 Scratch 官方规范中的自制积木只支持方形命令积木且无返回值，因此本框架为各个算子提供标准的方形命令积木（通过 `赋值给 "输出名称"` 将每次运算产出的新节点注册到指定名称）。

---

## 1. 核心损失函数与激活算子

### 1.1 Loss Functions

为神经网络训练计算目标误差张量与标量损失值。

#### 标准命令积木（方形）
```scratch
[MSELoss 预测: "预测名" 真实标签: "标签名" 赋值给 "输出名称"]

[CrossEntropyLoss Logits: "Logits名" 标签: "标签名" 赋值给 "输出名称"]

[BCELoss 预测: "预测名" 标签: "标签名" 赋值给 "输出名称"]

[L1Loss 预测: "预测名" 标签: "标签名" 赋值给 "输出名称"]
```
- **参数说明**：
  - `"预测名"` / `"标签名"`：参与计算的输入张量注册名称。
  - `"输出名称"` (String)：指定的输出绑定名。执行时会在动态图中计算并创建新输出节点，将新节点绑定注册到 `"输出名称"` 上。此后可通过名称获取或传递结果。
  - **BCELoss**：预测名为预测概率（sigmoid 后的输出），标签名为二值标签。内部自动对预测值做安全截断，避免 `log(0)` 数值溢出。
  - **CrossEntropyLoss**：要求 Logits 为 2D `[N, C]` 矩阵，标签为 1D 整数向量；会自动计算 softmax + NLLLoss。

---

### 1.2 激活与概率归一化

赋予神经网络非线性特征映射能力与分类概率归一化。

#### 标准命令积木（方形）

常规一输入一输出的激活函数统一为一个下拉积木：

```scratch
[对 Tensor "输入张量名" 应用 [ACT] 激活函数 赋值给 "输出名称"]
```

- **`[ACT]` 下拉选项**：`ReLU` / `GELU` / `Sigmoid` / `Tanh`
- **`"输入张量名"`**：输入张量注册名称。
- **`"输出名称"`**：结果输出绑定名。

 带额外维度的 Softmax 保持独立积木：

 ```scratch
 [Softmax 输入: "输入张量名" 沿维度: <数字 dim> 赋值给 "输出名称"]
 ```

 ### 1.3 缩放点积注意力

 为 Transformer 类架构提供多头注意力机制的核心算子。

 ```scratch
 [Scaled Dot Product Attention Q: "Q张量名" K: "K张量名" V: "V张量名" 因果掩码: <布尔值> 丢弃概率: <浮点数> 缩放: <浮点数> 赋值给 "输出名称"]
 ```

 - **输入形状**：Q / K / V 均要求为 4D `[B, H, L, D]`，其中 `B` 为 batch、`H` 为 head 数、`L` 为序列长度、`D` 为 head 维度。
 - **因果掩码**：`true` 时自动屏蔽未来位置（上三角置为 `-Infinity`），常用于解码器自注意力。
 - **丢弃概率 (dropoutP)**：对注意力权重矩阵应用 dropout；在 `[设置计算图追踪: false]` 推理模式下自动失效。
 - **缩放 (scale)**：可选手动缩放系数；留空或 `0` 时使用默认 `1 / sqrt(D)`。
 - **输出形状**：与 Q 相同 `[B, H, L, D]`。
 - **底层扩展**：算子实现层额外支持 `attnMask` 参数，可传入自定义注意力掩码张量（与 `-Infinity` 叠加的 additive mask）；该参数目前不暴露为 Scratch 积木，仅供 TypeScript API 直接调用。

## 2. 基础张量与数学代数算子

### 2.1 矩阵乘法与四则运算

矩阵乘法与四则运算统一在一个积木中，通过下拉菜单选择运算模式：

```scratch
[张量 [A] 与 [B] 进行 [OP] 运算 赋值给 "输出名称"]
```

- **`[OP]` 下拉选项**：
  - `+`：元素级加法（对应 `Add`）
  - `-`：元素级减法（对应 `Sub`）
  - `*`：元素级乘法（对应 `Mul`）
  - `/`：元素级除法（对应 `Div`）
  - `@`：矩阵乘法（对应 `MatMul`）

- **参数说明**：
  - `[A]` / `[B]`：参与运算的输入张量注册名称。
  - `"输出名称"` (String)：指定的输出绑定名。
  - **矩阵乘法支持**：一维向量点积、二维矩阵乘、一维与二维的矩阵-向量/向量-矩阵乘，以及三维及以上的批量矩阵乘与 batch 维度广播。`[@]` 下拉菜单是统一的矩阵乘入口，无需单独的 BMM 积木。

- **注意**：除法按元素进行，被 0 除将产生 `Infinity` / `NaN`，请避免以 0 作为除数。

### 2.2 元素级通用数学函数
对张量的每个元素逐一进行数学变换。

#### 标准命令积木（方形）

无额外参数的一元数学函数统一为一个下拉积木：

```scratch
[对 Tensor "张量名称" 计算 [OP] 赋值给 "输出名称"]
```

- **`[OP]` 下拉选项**：`Exp` / `Log` / `Sqrt` / `Abs`

幂运算因需额外指数参数，保持独立积木：

```scratch
[对 Tensor "张量名称" 计算幂 <数值幂 P> 赋值给 "输出名称"]
```

## 3. 形状与结构变换积木

### 标准命令积木（方形）
```scratch
[将 Tensor "张量名称" 重塑(Reshape)为 <Shape数组> 赋值给 "输出名称"]

[将 Tensor "张量名称" 转置(Transpose) 维度 <数字 dim1> 和 <数字 dim2> 赋值给 "输出名称"]

[在 Tensor "张量名称" 的维度 <数字 dim> 插入新维度(Unsqueeze) 赋值给 "输出名称"]

[移除 Tensor "张量名称" 大小为 1 的维度(Squeeze) 赋值给 "输出名称"]

[将 Tensor "张量名称" 广播(Expand)至目标形状 <Shape数组> 赋值给 "输出名称"]

[拼接张量列表: <名称字符串数组> 沿维度: <数字 dim> 赋值给 "输出名称"]

[堆叠张量列表: <名称字符串数组> 在新维度: <数字 dim> 赋值给 "输出名称"]

[将 Tensor "张量名称" 沿维度 <数字 dim> 均分为 <数字 n> 份 赋值前缀为 "输出前缀"]

[截取 Tensor "张量名称" 沿维度 <数字 dim> 从索引 <起 start> 到 <止 end> 赋值给 "输出名称"]

[条件选择(Where): 条件 "布尔Tensor名" 为真取 "Tensor名1" 为假取 "Tensor名2" 赋值给 "输出名称"]

[将 Tensor "张量名称" 裁剪数值范围至 <最小值 min> 到 <最大值 max> 之间 赋值给 "输出名称"]
```

- **Reshape**：元素总数不变，某一维可填 `-1` 自动推导。
- **Transpose**：交换两个维度；如 `[B, H, L, D]` 转置 dim1=1 dim2=2（不常用）。
- **Unsqueeze / Squeeze**：在指定位置插入或移除大小为 1 的维度。
- **Expand**：按广播规则扩展到目标形状（输出为持有完整数据副本的新张量，反向传播时将梯度求和归约回原形状）。
- **Concat**：沿已有维度拼接多个张量，不增加总维度数。
- **Stack**：在新维度上堆叠多个张量，总维度数 +1。
- **Split**：沿某维度等分为 n 份，输出结果命名为 `<前缀>_0`, `<前缀>_1`...。
- **Slice**：沿某维度截取 `[start, end)` 区间；反向传播仅回传梯度至被截取区域。
- **Where**：根据条件张量逐元素选取，支持广播。正向/反向自动路由梯度至对应分支。
- **Clamp**：将张量值限定在 `[min, max]` 范围内，超出部分梯度为 0。

## 4. 维度聚合操作

### 标准命令积木（方形）
```scratch
[对 Tensor "张量名称" 沿维度 <数字 dim> 进行 [OP] 保留维度: <布尔值 keepdim> 赋值给 "输出名称"]
```
- **维度聚合 `[OP]` 下拉选项**：`求和(Sum)` / `求平均值(Mean)` / `求最大值(Max)` / `求最小值(Min)`
- **参数说明**：
  - `<数字 dim>`：归约维度下标（支持负数索引；默认为 `-1`，即沿最后一维归约。若传入 NaN 则归约所有维度）。
  - `<布尔值 keepdim>`：是否保留被归约的维度，`false` 时与 PyTorch 默认行为一致。
  - **Max/Min 反向传播**：梯度仅回传至最大/最小值的第一个位置。

## 5. 归一化与正则化算子

为了提升深层模型的数值训练稳定度与抗过拟合能力，框架内置了标准的归一化与正则化功能积木。

### 5.1 LayerNorm
```scratch
[LayerNorm 输入: "输入张量名" 归一化最后 <数字 n> 维 赋值给 "输出名称"]
```
- **应用背景**：
  - `LayerNorm`（层归一化）：对单个样本序列的最后 n 个维度进行归一化（减均值除标准差），是 Transformer 与序列处理模型的核心组件。
  - **注意**：该实现为无可学习 affine 参数的 LayerNorm（即仅有减均值除标准差操作，无 gamma/beta 可训练参数）。
  - 参数 `<数字 n>` 不能超过输入张量的总维度数。

### 5.2 Dropout
```scratch
[Dropout 输入: "输入张量名" 丢弃概率: <浮点数 p> 赋值给 "输出名称"]
```
- **执行逻辑**：
  - **训练阶段**：按概率 `p` 随机将神经元输入设为 0，并自动对未丢弃元素进行缩放操作 `1 / (1 - p)`，以保持期望输出均值不变。
  - **评估阶段 (`[设置计算图追踪: false]`)**：自动禁用随机丢弃操作，恒等透传张量值。
